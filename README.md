# MET Landing Page

A modern landing page created for the Metropolitan Museum of Art (MET). The website presents essential information about the museum, its exhibitions, visiting hours, and contact details in a clear and attractive format.

## Project Overview

The MET Landing Page is a single-page website that gives visitors a quick overview of the Metropolitan Museum of Art. It contains information about the museum, its working hours, exhibitions, and ways to get in touch. The layout is designed to be simple, visually appealing, and convenient to use on different devices.

## Requirements

To run the project locally, you will need:

- **Node.js** (version 14.x or higher): A JavaScript runtime used to run the project.

- **NPM** (version 6.x or higher): A package manager for installing and managing dependencies.

## Installation

Follow these steps to launch the project:

1. **Clone the repository:**
```bash
git clone https://github.com/username/met-landing-page.git
```

2. **Open the project folder:**
```bash
cd met-landing-page
```

3. **Install the required packages:**
```bash
npm install
```

4. **Run the development server:**
```bash
npm start
```

5. Open `http://localhost:8080` in your browser to view the website.

## Main Features

- **Responsive Layout:** The website adapts to both desktop and mobile screen sizes.

- **Interactive Components:** JavaScript provides interactive features and improves the user experience.

- **Modern Design:** The page uses a clean and contemporary visual style.
